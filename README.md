# AZURE-BLOB-STORAGE-API

API em **.NET 8** para integração com o **Azure Blob Storage**, permitindo operações como upload, download e gerenciamento de arquivos em containers de forma simples e escalável.

## 🚀 Tecnologias
- C# / .NET 8
- Azure Blob Storage SDK
- ASP.NET Core Web API

## 📦 Funcionalidades
- Upload de arquivos para o Blob Storage
- Download de arquivos
- Listagem de blobs em um container
- Exclusão de blobs

## ⚙️ Configuração
1. Clone o repositório:
   ```bash
   git clone https://github.com/gureispt/AZURE-BLOB-STORAGE-API.git
2. Configure as credenciais do Azure no arquivo appsettings.json

3. Build e rode a aplicação:
  
  dotnet build
  dotnet run
